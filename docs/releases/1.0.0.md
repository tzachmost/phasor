# Phasor Shell 1.0.0

Phasor 1.0 is a portable desktop shell for MangoWM, built with Quickshell and QML. It keeps compositor and system integration behind `phasor-core` and loads first-party UI through the versioned plugin host.

## What's included

- A separate Phasor login session with wallpaper support, Mango Spaces, window controls, and documented shortcuts.
- A searchable app and Home file Launcher with pinning, open/reveal, copy path, share, duplicate, rename, and Trash actions.
- Live Settings for theme, accent, reduced motion, wallpaper, Desktop, and Dock.
- A top Bar with Spaces, clock, tray, notification status, clipboard history, screenshot capture, and Settings access.
- An optional window Dock and a Desktop surface with Home, Applications, and Settings shortcuts.
- A versioned local service API, plugin capability checks, diagnostics, and install/update/removal paths for supported distributions.

## Install

Choose the [installation guide](../install.md) for Arch/CachyOS, Fedora Workstation, Universal Blue/OSTree, or NixOS. The login session requires MangoWM and Quickshell. The install adapters provide the distribution-specific package setup.

## Release files

The 1.0.0 release assets are:

- `phasor-1.0.0.tar.gz` — reproducible source archive used by the stable Arch recipe.
- `phasor-shell-1.0.0-1-any.pkg.tar.zst` — Arch package.
- `phasor-shell-1.0.0-1.noarch.rpm` — Fedora and Universal Blue package.
- `phasor-shell-1.0.0-1.src.rpm` — RPM source package.
- `SHA256SUMS` — checksums for the source archive and binary/source packages.

Verify downloaded assets with `sha256sum -c SHA256SUMS`. NixOS builds the package from the tagged flake source.
