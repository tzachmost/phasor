# Shell 1.0 scope

The Launcher is a dark, compact overlay over a solid-color or configured SwayBG wallpaper. It shows pinned apps first in a grid when the query is empty, then provides ranked app and file results as the user types. Enter launches an application or opens a file; Escape closes the overlay. Hidden directories and removable/mounted filesystems are excluded from the default Home index.

The top Bar shows the active Mango Spaces, a clock, tray icons and a Settings entry point. The optional bottom Dock lists running windows and lets users focus or close them. Its Settings controls can hide close buttons and the empty-state label. Both surfaces use independent edge reservations and can run together. Tray menus are provided by the StatusNotifierItem protocol.

Design tokens live centrally in `shell/theme/Tokens.qml`. The visible UI reads the user's dark, light, or system theme, accent, and reduced-motion settings through the core. Components should use tokens for shared colors, spacing, radii, and animation durations. The launcher supports pin/unpin, app info, opening an app's AppStream page, file open, reveal, copy path, share link, duplicate, rename, and move to Trash. Mango Space shortcuts and the core Spaces API remain available alongside the in-launcher Space switcher.

Settings is a standalone desktop application, opened from Launcher, the Bar, `phasor-settings`, or its configurable shortcut. It runs separately from the shell, supports normal tiling and minimize/restore, and reuses its existing window when opened again. Its Appearance page edits the theme, accent, reduced-motion, and wallpaper preferences. Its Desktop page enables or hides the Bar, Launcher, Desktop shortcuts, Dock, command palette, clipboard history, notification controls, and screenshot action; it also controls recent app ranking, Dock window controls, Space count and animation, and window focus behavior. The System page controls Wi-Fi, Bluetooth power, PipeWire output volume, display brightness, and Do Not Disturb through the existing service adapters. It reports a control as unavailable when its backend utility or hardware is missing. Keyboard shortcuts and project information have their own pages. The keyboard page changes Launcher, Commands, and Settings shortcuts; Super+/ opens the searchable Commands palette by default, and its "Change keyboard shortcuts" action opens that page directly. Shortcut and Space changes rewrite and hot-reload the private Phasor Mango session config. If `PHASOR_MANGO_CONFIG` selects a custom config, Phasor saves those preferences and explains that the custom file remains active. All preferences remain in the validated per-user file; Appearance, Desktop, and shortcut changes use explicit Save actions, while device controls apply immediately.


The Tiling page provides illustrated Grid, Main + stack, Centered, Top + stack, Columns, Rows, One at a time, and Deck choices. Grid remains the default. GUI controls cover independent inner/outer horizontal/vertical gaps, smart gaps, border width and single-window borders, main-window count and proportion, placement of new windows, scroller size and centering, and split behavior. Apply tiling saves validated preferences and reloads the active managed configuration. The advanced native editor remains available; shared settings own the corresponding native keys. Defaults and ranges are documented by `config/schema/settings.schema.json` under `tiling`.

Dock icons retain identity across refreshes. Only additions, removals, and moves animate; hovering lifts an icon and reveals a window card with Minimize/Restore and Close. Clicking the active icon minimizes it, clicking a minimized icon restores and focuses it, and right-click opens its card immediately. Empty portions of the bottom edge pass pointer input through. Launcher ignores obsolete asynchronous searches and takes exclusive keyboard focus when opened. Grid navigation uses the actual number of columns.

Motion timings share the Spaces animation-duration preference between the compositor and shell. Reduced motion makes shell durations zero and disables compositor animations. Angular glass surfaces and common controls are shared by Launcher, Actions, Dock, and Settings.

UI regression checks: `QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qmltestrunner -input tests/qml`. These exercise delegate identity through refresh/reorder and asynchronous search cancellation. `python3 -m unittest discover -s tests -p 'test_tiling.py'` (with `PYTHONPATH=core`) covers validation, persistence, native rendering, reload, and shared motion settings.
