# Shell 1.0 scope

The Launcher is a dark, compact overlay over a solid-color or configured SwayBG wallpaper. It shows pinned apps first in a grid when the query is empty, then provides ranked app and file results as the user types. Enter launches an application or opens a file; Escape closes the overlay. Hidden directories and removable/mounted filesystems are excluded from the default Home index.

The top Bar shows the active Mango Spaces, a clock, tray icons and a Settings entry point. The optional bottom Dock lists running windows and lets users focus or close them. Its Settings controls can hide close buttons and the empty-state label. Both surfaces use independent edge reservations and can run together. Tray menus are provided by the StatusNotifierItem protocol.

Design tokens live centrally in `shell/theme/Tokens.qml`. The visible UI reads the user's dark, light, or system theme, accent, and reduced-motion settings through the core. Components should use tokens for shared colors, spacing, radii, and animation durations. The launcher supports pin/unpin, app info, opening an app's AppStream page, file open, reveal, copy path, share link, duplicate, rename, and move to Trash. Mango Space shortcuts and the core Spaces API remain available alongside the in-launcher Space switcher.

The Settings surface opens from the Bar or its configurable shortcut. Its Appearance page edits the theme, accent, reduced-motion, and wallpaper preferences. Its Shell page enables or hides the Bar, Launcher, Desktop shortcuts, Dock, command palette, clipboard history, notification controls, and screenshot action; it also controls recent app ranking, Dock window controls, Space count and animation, and window focus behavior. The System page controls Wi-Fi, Bluetooth power, PipeWire output volume, display brightness, and Do Not Disturb through the existing service adapters. It reports a control as unavailable when its backend utility or hardware is missing. Keyboard shortcuts and project information have their own pages. The keyboard page changes Launcher, Commands, and Settings shortcuts; Super+/ opens the searchable Commands palette by default, and its "Change keyboard shortcuts" action opens that page directly. Shortcut and Space changes rewrite and hot-reload the private Phasor Mango session config. If `PHASOR_MANGO_CONFIG` selects a custom config, Phasor saves those preferences and explains that the custom file remains active. All preferences remain in the validated per-user file; Appearance, Shell, and shortcut changes use explicit Save actions, while device controls apply immediately.
