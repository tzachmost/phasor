# Development handoff

Phasor 1.0.0 is published. The current priority is finishing and validating the Settings app and its session preferences; then return to Preview's Spacebar Quick Look flow and broad format coverage. Read this page with [the roadmap](roadmap.md), [architecture](architecture.md), and [the plugin API](plugin-api.md).

## Current implementation

The v0.1 foundation and the Bar, Dock, Desktop, Commands, and service surfaces are implemented. The repo includes the Phasor session supervisor, Quickshell plugin host, validated core configuration and local service API, Mango Space/window controls, Launcher, full Home file actions, live theme/wallpaper settings, a top Bar, an optional window Dock, the searchable Commands palette, and Desktop shortcuts over the wallpaper. The Bar shows workspaces, clock, tray items, notification count, Do Not Disturb, clipboard history, screenshot capture, and Settings. The Dock can focus and close running windows and has settings for its close buttons and empty state. Settings now has Appearance, Shell, System, Shortcuts, and About pages; Launcher recents, Space count/animation, focus behavior, and Launcher/Commands/Settings shortcuts are saved and applied, with Phasor-owned Mango settings hot-reloaded in session. The Commands palette opens on Super+/ by default and can open Settings directly to its shortcut page. Wi-Fi, Bluetooth, audio, brightness, and Do Not Disturb controls report unavailable backends clearly. These surfaces can run together.

Preview is implemented as a standalone Wayland application. It opens images and PDFs; supports PDF page navigation, thumbnails, embedded table-of-contents bookmarks, text search/copy, and single-page, continuous-scroll, and two-page reading layouts; and reads common AcroForm fields, including multi-line fields, editable choices, multi-select lists, and masked password fields. Reading layouts that use the original page order are available after page operations are reset. Preview provides a document information panel for PDF metadata and image properties; plays and browses animated image frames; provides image/PDF markup and visual signature strokes with autosaved sidecars; and exports image copies or PDFs with searchable source content and editable form fields. PDF text selection can create quote-anchored highlights, underlines, strike-throughs, and notes; the sidecar retains their selected text and page geometry, and exported notes remain standard PDF text annotations. New password-field entries remain out of autosaved sidecars and travel to the document helper over standard input during explicit output actions. Password-protected PDFs can be unlocked with a session-only password, then exported, printed, merged, or signed into a new copy. From the Page menu, Preview can insert a blank page or selected pages from another PDF and opens the resulting copy; it applies current markup, form values, order, and rotation while leaving the source documents unchanged. Imported form fields are namespaced. PDF copies can receive AES-256 protection and lossless stream/object compression. Image export supports crop, horizontal and vertical flip, rotation, selected animation frame, resize, format conversion, and quality settings. Lasso selection extracts a freeform area into a transparent PNG, applying the selected frame and image transforms without changing its source. Optional background removal uses a local CPU model and exports a transparent PNG copy without changing the source image. Optional local OCR can recognize text in transformed image frames and export searchable PDF copies while applying pending PDF page operations; PDF passwords remain on standard input and signed PDFs are refused. PDF export supports markup, page reorder, exclusion, form values, and per-page rotation while preserving the source file. Preview can permanently redact affected pages in exported, printed, and merged copies; those pages are rasterized so the covered source objects cannot be extracted. It can merge the current prepared PDF with other unsigned documents into a new copy, print through CUPS, and digitally sign PDFs with visible PKCS#12 certificate signatures in new copies. It refuses to merge signed documents because rewriting them would invalidate their signatures, keeps existing signed revisions intact when digitally signing, and rejects pending edits that would invalidate a prior signature. The 1.1.0 development package includes Pillow, pypdf, ReportLab, cryptography, WebP support, and DejaVu Sans for export; pyHanko is included in Nix, optional on Arch, and documented as a private venv install on Fedora. OCRmyPDF and Tesseract are optional system tools; the Nix flake has a separate `preview-ocr` output.

Arch/CachyOS, Fedora, Universal Blue/OSTree, and NixOS install, update, diagnostics, and removal paths are documented. The versioned Arch recipe, Fedora RPM/SRPM, and NixOS flake package have built and passed artifact inspection. Isolated package transactions and a fresh CachyOS session run are complete. The reviewed source commit, `v1.0.0` tag, packages, checksums, and user documentation are published in the [GitHub release](https://github.com/tzachmost/phasor/releases/tag/v1.0.0). The stable Arch recipe still needs an AUR SSH key before it can be submitted; that distribution follow-up does not block the completed 1.0 roadmap checklist.
